Composer inside FlowForge

The copilot in FlowForge that builds agents with you. I designed it. The first version in Feb 2026 was a PydanticAI agent with 21 tools that could change pretty much anything on an agent: settings, voice, tools, knowledge base, flows, test chat. Now it sees whatever page you're on, can drive the UI for you and asks before it does anything consequential. It has a skills system too (SKILL.md files loaded from the DB, same shape as Claude Code skills).

On my own GPU May 2026

A fully self-hosted voice agent on one RTX 6000 Ada on RunPod. Sesame CSM-1B fine-tuned with LoRA on a custom voice, next to a LiveKit worker. First audio went from 4.9s to about 315ms warm and live calls come in under 400ms end to end.

Same month I moved the end-of-turn model onto the GPU in fp16 PyTorch. p50 is 23ms, it used to be 300 to 400ms.
